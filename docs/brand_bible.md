# Action Replay Brand Bible

Internal helper-agent file. Not a public page. Do not publish this as site copy.

## Core

Action Replay is a fictional cultural artifact that leaks into real product, not a normal apparel label.

The brand behaves like a recovered cheat-device archive: old retail sheets, import catalog energy, corrupted menu logic, packaging mistakes, hidden file labels, product evidence, and people talking like they found something before the account was ready.

Core line:

```text
don't cheat the player, cheat the game.
```

## The World

Action Replay should feel like:

- a lost cheat device still updating somewhere,
- a 2007 import catalog with a bad scan bed,
- a shop folder copied from somebody's dead laptop,
- a forum thread that became physical product,
- a media page with garments hidden inside it,
- a collector subculture forming before anyone named it.

Do not flatten the world into one fixed style. Preserve drift between DS menu, PS2 save screen, old retail sticker, direct flash photo, paper scan, product reality, and quiet customer proof.

## Voice

Use short, compressed language. Let the sentence feel like an operator note or a caption saved at 2:14AM.

Good:

- `slot b opened before the image finished loading`
- `quantity posted when boxes are counted`
- `same file family, different damage`
- `the first run closed. not deleting the bad files`
- `if duplicate appears, keep the older one`
- `wrong purple approved by nightstaff`

Avoid:

- "premium streetwear experience"
- "limited capsule engineered for culture"
- "join the movement"
- "nostalgia meets innovation"
- clean jokes, viral bait, and overexplained lore.

## Product Reality

Product must keep showing up as evidence. Use real proof when available:

- fabric closeups,
- neck tags,
- labels,
- packing mistakes,
- order counts,
- worn photos,
- shipping prep,
- inventory notes,
- customer reposts,
- screenshots of clean metrics only when they help decisions.

Do not invent sales, orders, reviews, partnerships, or customer proof.

## Archive Grammar

Use in-world file language:

- `AR-001`
- `SLOT A`
- `SLOT B`
- `RESTORED RUN`
- `EVENT FLAG`
- `BUILD NOTE`
- `FILE LOCKED`
- `LAST VERIFIED`
- `M-CARD REV`
- `LOCALIZATION ERROR`

One unexplained detail per artifact is enough. More than that starts to feel written.

## Account Roles

Main account: finished evidence, drop state, product proof, strong artifacts.

Side archive accounts: slower, damaged, narrower, less consistent. They should not all sound like the same person wearing different usernames.

External pages: paid or unpaid repost partners only when the placement is clear enough to be ethical. Never ask a page to claim fake history is real.

## Growth Taste Rule

The highest-value post is not always the cleanest post. For early Action Replay, rank creative by:

1. saves,
2. sends and shares,
3. non-follower reach,
4. profile visits,
5. follows per reach,
6. comments with actual recognition,
7. site clicks and commerce events.

Likes are useful only after the stronger signals are understood.

## Hard Constraints

- No fake engagement.
- No automated commenting.
- No follower buying.
- No engagement pods.
- No scraping private or restricted data.
- No platform ban evasion.
- No deceptive real-world claims.
- No stolen creative assets.
- No visual asset generation in this helper-agent setup.

The system can be strange. It cannot be fraudulent.
