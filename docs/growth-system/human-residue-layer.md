# Human Residue Layer

This file is not another content system.

It is the stain left on the systems that already exist.

The growth engine is correct. The account universe is correct. The hidden-code mechanics are correct. Do not rebuild them. Make them feel maintained by someone who has been carrying the same obsolete folder structure for too long.

## Main Rule

Every artifact should contain one trace that would exist only because a person touched it, forgot it, duplicated it, renamed it badly, or cared too much about something too small.

Not a joke.
Not a puzzle.
Not a lore reveal.

A trace.

## What Changes Now

Before publishing an artifact, ask:

```text
what would be left behind if this file had been opened, exported, argued over, renamed, and half-abandoned for years?
```

Then add one thing:

- a wrong timestamp,
- a duplicate filename,
- a repeated username,
- a damaged note,
- a leftover localization string,
- an obsolete warning,
- a hardware revision that never mattered,
- a tiny emotional attachment to an object nobody asked about,
- a dead route,
- a discontinued label,
- a half-erased internal phrase.

Only one or two. More starts looking performed.

## Human Scars To Add

### Accidental Duplication

Examples:

- `poster_final.psd`
- `poster_final_REAL.psd`
- `poster_final_REAL_USE.psd`
- `poster_final_REAL_USE_2_old.psd`

Use when an artifact should feel like it came from production, not a content calendar.

### Emotional Attachment To Meaningless Objects

Examples:

- keep the wrong blue sticker because it was on the first box,
- mention a silver DS model nobody sees,
- preserve a rejected tag because `mira_local liked the tear`,
- refuse to restore a dead sponsor line,
- keep a broken QR code because three people scanned it anyway.

### Conflicting Naming Systems

Let the same thing have multiple names:

- `AR-002`
- `SLOT B`
- `second restored run`
- `M-CARD REV E`
- `night export`

Do not reconcile them immediately.

### Dead Experiments

Keep traces of things that failed:

- `EUROPEAN DISTRIBUTION CANCELLED`
- `DEV-02 NEVER SHIPPED`
- `temp localization file`
- `mirror build nav abandoned`
- `forum badges removed`
- `silver model warning kept`

These do not need future payoff.

### Obsolete Warnings

Use warnings that sound operational but strange:

- `DO NOT RUN ON SILVER MODEL`
- `do not restore after 12:17`
- `slot b labels must not touch heat`
- `do not translate the warning line`
- `if duplicate appears, keep the older one`
- `manual save disabled during event`
- `wrong purple approved by nightstaff`

## Where To Inject Residue

### Captions

Add one small scar after the main sentence:

```text

wrong purple approved by nightstaff.
```

```text
the clean file is missing.
last verified 2007.
```

### Image Assets

Add:

- a layer name,
- a tiny sticker code,
- a handwritten correction,
- an export timestamp,
- a dead thumbnail,
- a duplicate filename,
- a wrong page number.

### Website

Add:

- dead pages with useful 404 copy,
- obsolete route names,
- hidden build labels,
- localStorage keys that sound like save data,
- small system logs,
- missing attachment placeholders,
- disabled buttons that imply old functionality.

### Side Accounts

Each account should have one private obsession:

- `replay_recovered`: duplicate filenames and the blue folder.
- `override_monthly`: page 17 and issue 00.
- `slotb_testers`: bugs that feel better than fixes.
- `memorycard_err`: silver model warnings.
- `unlock_log_txt`: timestamps and denied hints.
- `bbs_mirror_2007`: missing avatars and page 2.

## Residue QA

Keep the artifact if:

- it feels like someone used it before you saw it,
- one detail seems too specific to explain,
- it implies labor without bragging,
- it creates a small contradiction,
- it would be worse if cleaned up.

Reject it if:

- the weirdness is the whole point,
- the clue feels like an escape room,
- the mystery asks for too much attention,
- the language sounds like a trailer,
- every detail is perfectly aligned with the brand.
