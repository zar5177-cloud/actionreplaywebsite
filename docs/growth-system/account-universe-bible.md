# Account Universe Bible

Use side accounts like old folders, not like growth hacks. Each one has a job, a posting defect, and a relationship to the main account. Keep the fiction legible enough that nobody feels tricked: fictional archive account, Action Replay universe, link/hint in highlight, no impersonation of real publications.
