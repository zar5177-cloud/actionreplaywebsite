# Comment And Caption Bank

Use these as source material, not copy-paste ammunition. Change punctuation, casing, and one concrete detail every time. Never deploy the same comment across multiple accounts. Leave comments only when the post or conversation actually connects.

## Controlled Comment Rules

- Max 8-15 outbound comments per account per day.
- No link in comment unless the creator asked for it.
- No “check us out,” “DM us,” “collab?” or “use code” language in public comments.
- Side accounts can comment on main account posts, but only if the account has a reason to know something.
- Main account should reply less than people expect. Scarcity applies to attention too.
- If someone calls it fake, do not argue. Reply with a tiny artifact detail or ignore.
