# Campaign Checklist

Internal Action Replay HQ doc.

Before posting:

- create UTM link in `/admin/utm-builder`;
- choose matching landing page `/r/[slug]`;
- confirm Replay Club capture is visible;
- confirm product CTA is visible on mobile;
- confirm code/archive action is tracked if relevant;
- write down the exact creative name for `utm_content`;
- screenshot the post/story insight after 24 hours;
- enter metrics into the manual data files.

After posting:

- check Shopify sessions;
- check Clarity recordings;
- check `window.dataLayer` or GA4 DebugView;
- log rage/dead clicks;
- note comments that reveal confusion or recognition;
- decide whether to create a follow-up artifact, not whether to over-polish.
